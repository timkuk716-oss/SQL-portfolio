# SQL-портфолио — витрина навыков

Набор SQL-запросов на небольшой учебной базе интернет-магазина. Показывает работу
с выборками, джойнами, агрегацией, оконными функциями, подзапросами и NULL.
Запускается одной командой через Python (встроенный SQLite — **ставить ничего не нужно**).

## Как запустить

Нужен только Python 3.

```bash
python run.py
```

Скрипт создаёт базу в памяти из `schema.sql`, по очереди выполняет все запросы
из `queries.sql` и печатает результаты.

## Структура

```
sql-portfolio/
├── schema.sql    # схема (5 таблиц) + тестовые данные
├── queries.sql   # 18 запросов, каждый с комментарием, что он демонстрирует
├── run.py        # запускает все запросы и печатает результаты (SQLite)
└── README.md
```

## Схема

- `customers` — клиенты (город, пол, дата регистрации)
- `employees` — сотрудники (зарплата, `manager_id` → руководитель)
- `products` — товары (категория, цена)
- `orders` — заказы (клиент, сумма, статус, дата)
- `order_items` — позиции заказов (связывает `orders` и `products`)

## Что демонстрируется

| # | Тема | Конструкции |
|---|------|-------------|
| 1 | Выборка и фильтрация | `WHERE`, `AND/OR`, `IN`, `BETWEEN`, `DISTINCT` |
| 2 | Поиск по тексту | `LIKE`, шаблоны `%` `_` |
| 3 | Агрегация | `COUNT(*)` vs `COUNT(col)`, `SUM`, `AVG`, `MAX`, `ROUND`, `COUNT(DISTINCT)` |
| 4 | Группы | `GROUP BY` + `HAVING` |
| 5 | Условия | `CASE WHEN` |
| 6 | Сортировка | многоуровневый `ORDER BY`, `LIMIT` |
| 7 | Джойны | `INNER JOIN` |
| 8 | Джойны | `LEFT JOIN` (и как `COUNT` ведёт себя с `NULL`) |
| 9 | Джойны | Anti-Join (`LEFT JOIN ... IS NULL`) |
| 10 | Джойны | Self-Join (сотрудник ↔ руководитель) |
| 11 | Джойны | соединение 3+ таблиц через связующую |
| 12 | NULL | `COALESCE`, `IS NULL` |
| 13 | Подзапросы | сравнение со средним |
| 14 | Подзапросы | `EXISTS` |
| 15 | Множества | `UNION` / `UNION ALL` |
| 16 | Оконные функции | `ROW_NUMBER`, `RANK`, `DENSE_RANK` (видна разница при ничьей) |
| 17 | Математика | остаток от деления `%` |
| 18 | Даты | фильтр по периоду (+ эквиваленты для MySQL/PostgreSQL в комментарии) |

## Про диалект

Запросы написаны на стандартном SQL и проверены на **SQLite** (чтобы запускались
без установки сервера). Подавляющее большинство конструкций одинаково работает в
**MySQL** и **PostgreSQL**; там, где синтаксис отличается (например, функции дат),
в `queries.sql` рядом стоит комментарий с эквивалентом.
